# 系统要求

| 平台 | 架构 | 状态 |
|------|------|------|
| macOS | Apple Silicon | 支持 |
| macOS | Intel（x64） | 支持 |
| Windows | x64 | 支持 |
| Linux | — | 暂不支持 |

安装包与版本号以 [官网下载页](https://www.safeclaude.net/#download) 为准。当前推荐 **v1.1.0**，说明见 [更新日志](Changelog)。

## 使用建议

- 扫描前尽量关闭正在大量读写配置的 Agent 会话，避免文件占用导致部分项跳过
- 若系统开启了多重代理 / VPN，出站 IP 相关结果可能随网络切换变化，建议在稳定网络下复扫对比
- 自动修复（Pro）会改写本机时区、Shell 或 Agent 配置；请先阅读风险详情再确认

## 权限说明

部分检测依赖读取系统代理、时区与用户目录下的 Agent 配置。若 macOS 提示隐私权限，请按系统弹窗授权；拒绝后相关检测项可能显示为无法完成或跳过。
