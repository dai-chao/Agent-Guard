# 运行时 Hook（附加能力）

运行时 Hook 是 **可选的行为审计能力**，与「环境合规扫描」相互独立：前者管**环境指纹与配置泄漏**，后者管 **Agent 执行过程中的高危操作**。

## 能力概览

- 为 Cursor、Claude Code、Codex 等接入**原生 Hook**
- 高危操作弹窗审批；红线操作直接拒绝（如 `rm -rf /`、`curl | bash`）
- 40+ 安全规则，操作可输出 0–100 安全评分  
- 攻击链检测示例：
  - 读 `.env` → 网络外传  
  - 下载 → `chmod` → 执行  

## 使用建议

- 先完成环境合规扫描与必要修复，再按需开启 Hook  
- Hook 可能打断自动化工作流；团队环境请先约定审批策略  
- 红线规则通常不可审批放行，属安全设计而非故障  

具体支持的 Agent 与规则列表以应用内展示为准。
