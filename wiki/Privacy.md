# 隐私与边界

## 隐私承诺

- 扫描与修复均在 **本机** 完成  
- **数据不上云**  
- 自动修复前备份原配置，可随时回滚（`~/.agent-guard/backups/`）

## 会做什么

- 读取本机时区、系统代理、Shell / 工具链配置  
- 读取已安装 Agent 的配置文件（如 settings、MCP 配置等）  
- 检测出站 IP 类型与地理一致性（用于合规评分）  
- Pro 在用户确认后，自动修复部分项并备份  

## 不会做什么

- 不上传扫描结果或配置内容到云端  
- 不在未确认的情况下静默改写系统或 Agent 配置  
- 不替代官方客户端  
- 不提供账号、订阅，也不提供绕过平台风控的能力  

## 本仓库说明

本 GitHub 仓库主要用于产品说明与社区讨论；**Agent Guard 客户端为专有软件，源码未在此开源**。安装与使用条款以官网为准。

## 反馈时请注意

请勿在 Issue / Discussions / 群聊中粘贴 API Key、Token、完整配置文件或可识别个人身份的敏感路径。需要截图时请先打码。
