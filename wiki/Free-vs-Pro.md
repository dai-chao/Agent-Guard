# 免费版与 Pro

| 能力 | 免费版 | Pro |
|------|--------|-----|
| 本机环境扫描 | ✅ | ✅ |
| 红 / 黄 / 绿合规灯与评分 | ✅ | ✅ |
| 风险详情与手动修复指引 | ✅ | ✅ |
| 一键自动修复 | ❌ | ✅ |
| 修复前自动备份 | — | ✅ |
| 数据不上云 | ✅ | ✅ |

购买与权益以 [官网](https://www.safeclaude.net/) 展示为准。

## 怎么选

- **只想先摸清风险**：免费扫描足够  
- **需要批量清理时区 / 代理 / 配置残留**：Pro 更省事，且有备份  

运行时 Hook 守护为附加能力，说明见 [运行时 Hook](Runtime-Hooks)。
