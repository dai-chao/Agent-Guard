## v1.1.1（2026-08-25）

**Windows 可用、Skill 同步可靠，本机痕迹清理装完即用。**

上一版把封号热点检测项推上来之后，反馈最集中的是三件事：Windows 装完接不上守护、Skill「待同步」点了却不收敛、痕迹清理还要用户自己折腾依赖。v1.1.1 把这三条链路打通——装完即可用，同步状态跟得上，清理引擎随包内置。

### Windows 深度修复

- 修正 Hook 识别、命名管道传输与探测错位等问题，Windows 安装后可正常接入守护链路。
- 提供安装包 / 便携版，按芯片与使用场景选择即可，装完即可用。

### Skill 同步状态修正

- 「待同步」点击同步后可正确收敛，侧栏角标随状态刷新，不再卡在半途。
- 区分「可自动同步的漂移」与「需手动解决的多方冲突」，该自动修的自动修，该你拍板的才打断你。

### 痕迹清理升级

- 支持文本隐藏字符、图片元数据 / C2PA，以及 PDF、DOCX、EPUB、音视频等容器级溯源清理。
- Mac / Windows 随包内置本地引擎，无需用户另装服务；清理仍在本机完成，不上云。

### 智能保养全面体检

- 一键按模块体检：Agent → 防封 → 护栏 → Skill → 组件。
- 弹窗进度与停止，不再误跳成「只跑防封扫描」。

### 体验与门禁打磨

- 账号菜单、版本号展示、顶栏玻璃与 Pro 门禁更顺。
- 防封规则继续覆盖代理残留、时区出口、明文密钥、非官方端点等高危信号。

### 升级后建议

1. 升级到 v1.1.1（Windows 用户优先验证 Hook / 防护是否已接入）
2. 打开「智能保养」跑一轮全面体检，或至少先跑「防封扫描」清红灯
3. 若侧栏仍有 Skill「待同步」，点同步确认可收敛项已落下；多方冲突按提示手动处理
4. 需要外发材料时，用痕迹清理过一遍再出门；复扫留底

## v1.1.0（2026-08-06）

**跟进封号热点，检测规则实时加码。**

最近封号又紧，很多手法刚在社区传开，本机里对应的代理残留、中转端点、明文 Key 可能早就躺着了。这版重点就一件事：新闻里出什么新风险，我们尽快加进检测项，别等号没了才发现。

### 跟进实时新闻，检测项持续加码

- 跟踪 Claude、Cursor、Codex 等平台近期封号潮、风控收紧与社区复盘，把新出现的环境信号沉淀为可复现的检测规则
- 针对大规模封号期间高频特征（异常中转、配置泄漏、时区与出口不一致、共享出口跳变等）加严判定
- 规则库支持更快迭代：行业一有新的封号手法或中转痕迹特征，检测清单就能跟上
- 热点专项场景与本机扫描联动更顺——先看新闻里在盯什么，再在本机对号入座

### 防封与安全模块全面升级

| 模块 | 说明 |
|------|------|
| 防封扫描 | 首页总览 + 检测页更清晰，红 / 黄 / 绿灯优先展示高危信号 |
| 防护 | 运行时策略与守护加强，高危操作尽量拦在执行前 |
| 隐私扫描 | 强化明文 Key、敏感配置等本机暴露风险排查 |
| 系统诊断 | 定位安装、依赖与环境连通性问题 |
| 调用日志 | 留住 Agent 与防护相关操作轨迹，异常时可回溯 |
| Skill 整理 | 盘点本机 Skills，降低来路不明能力成为风险入口的概率 |

### 高危信号覆盖加宽

- 代理残留（Shell / 工具链 / Agent 配置）、时区与出口不一致、明文 MCP 密钥、非官方 API 端点、OAuth 中转等继续加宽
- 弱信号叠加时的预警更敏感
- 修复与复扫闭环：能自动处理的项修复前备份；修完立刻复扫确认红灯是否降下

### 升级后建议

1. 升级到 v1.1.0，打开「防封扫描」先跑一轮完整检测
2. 优先处理红灯：代理残留、配置泄漏、明文密钥、非官方端点
3. 再看防护与隐私扫描，确认运行时守护与敏感信息没有裸奔
4. 复扫一次留档
